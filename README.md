# ABIBOK.pl — pakiet przekazania

Gotowy pakiet źródłowy dla projektanta, developera i osoby przygotowującej treści.

## Najważniejsze pliki

- `ABIBOK_FINAL_SPEC.md` — kompletne, nadrzędne TZ projektu (sekcje 1–21.10).
- `ABIBOK_FINAL_SPEC.docx` — wersja do czytania, komentowania i przekazania.
- `content/pages.pl.json` — treści stron i formularza w języku polskim.
- `design/design-tokens.json` i `design/tokens.css` — tokeny projektowe.
- `design/asset-brief.md` — wytyczne dla fotografii, ikon i logotypu.
- `implementation/acceptance-checklist.md` — checklista odbioru strony.
- `implementation/routes-and-cta.md` — routing, CTA i zachowanie linków.
- `open-questions.md` — dane, których nie wolno wymyślać przed publikacją.

## Zasada nadrzędna marki

Nazwa występuje wyłącznie jako **ABIBOK**. Druga litera **B** w znaku graficznym jest odbita poziomo. Nie używać napisów `ABEBOK`, `AƂIBOK` ani innych imitacji z generatorów jako gotowego logo. W zwykłym tekście, nazwach plików, alt-textach i danych strukturalnych używać poprawnego tekstu `ABIBOK`.

## Wdrożenie

Docelowy katalog: `D:\abibok.pl`. Po rozpakowaniu zachować strukturę pakietu. Dane oznaczone jako placeholdery uzupełnić przed uruchomieniem produkcyjnym.
