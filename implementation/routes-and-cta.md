# Routing i CTA

| Element | Cel |
|---|---|
| Logo | `/` |
| Usługi | `/uslugi` |
| Jak to działa | `/#jak-to-dziala` |
| Ceny | `/#ceny` |
| FAQ | `/#faq` |
| O nas | `/o-nas` |
| Kontakt | `/kontakt` |
| Zamów / Opisz | `/zamow-usluge` |
| Zapytaj o usługę | `/zamow-usluge?service=<slug>` |
| Zadzwoń | `tel:[NUMER]` |
| WhatsApp | `https://wa.me/[NUMER]` |

`service` wypełnia kontekst zgłoszenia. PL bazowy; architektura przewiduje `/en/` i `/ru/`; hreflang dopiero po pełnych tłumaczeniach.
